A one-line funny rant about an everyday annoyance — "Circling Back": the person who writes "just circling back" on an email you already answered, like a vulture with a calendar invite. Entry for make.fun's "Angry Judge: The Short Rant Contest" bounty ($2, top 3 paid $1/$0.50/$0.50). The program scores 10 candidate rants against the judge's five criteria (weights 5/4/3/2/1, max 30), picks the winner at runtime, and writes it to /output/entry.txt.

> He wrote 'just circling back' on an email I answered yesterday, like a vulture with a calendar invite, and now I owe him a reply for a reply he already got.

## Run it

```sh
node main.ts
```
